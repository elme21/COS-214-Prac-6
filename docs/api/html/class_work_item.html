Detailed Description

The WorkItem class is the Context of the State pattern, the AbstractClass of the Template Method pattern, a Leaf of the Composite pattern and a Colleague of the Mediator pattern. Template Method: execute() is the final skeleton (checkReady -> onEnter -> perform -> recordResult); subclasses supply the primitive operation perform() and may override the hooks onEnter() / recordResult(). State: all lifecycle operations delegate to the current state, which returns true if the transition happened and false if it is not allowed. Only WorkItemState (friend) may change the state or assignee during normal transitions; restoreState() is the silent back door used only by command undo.
