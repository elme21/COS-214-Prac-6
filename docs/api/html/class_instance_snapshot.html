Detailed Description

Immutable snapshot (Memento) capturing the state and component hierarchy of a WorkflowInstance.

Stores the workflow status, a cloned root component tree, and the timestamp when the snapshot was taken. State restoration logic is restricted to WorkflowInstance via friend declaration.
