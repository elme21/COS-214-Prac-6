ApprovalTask Class Reference

The ApprovalTask class is a ConcreteClass of the Template Method pattern (and a Composite leaf): a task decided by a chain of approvers; the decision arrives as approve() or reject(). It is the Client of the Chain of Responsibility pattern. After each run of the chain it keeps the result as plain data (the handlers the request visited, who decided and what was decided), readable through the getChain...() getters. Detailed Description

The ApprovalTask class is a ConcreteClass of the Template Method pattern (and a Composite leaf): a task decided by a chain of approvers; the decision arrives as approve() or reject(). It is the Client of the Chain of Responsibility pattern. After each run of the chain it keeps the result as plain data (the handlers the request visited, who decided and what was decided), readable through the getChain...() getters. The result holds no pointers, so clone() simply copies it and a clone never refers back to the original task.

bool ApprovalTask::perform ( )
overrideprotectedvirtual

the primitive operation: clears the previous chain result, then sends an ApprovalRequest(this, requestValue) to the first handler. The handler that decides calls approve() or reject() on this task itself. Afterwards the request's path, outcome and decider are kept as the chain result. With no chain configured it prints a message and leaves the result as "no decision yet".

Returns
always false, so recordResult() does not complete the task again: the decision has already been applied by the chain
