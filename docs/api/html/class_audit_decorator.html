Detailed Description

Records each lifecycle attempt, including refused ones.

Place it outermost in a decorator stack so attempts refused by inner decorators (for example a wrong-role approval) are audited too. The sink is wired by the workflow builder, e.g. to the event publisher.

Design pattern
Decorator (ConcreteDecorator role).
