Detailed Description

Observer - ConcreteObserver. Tracks deadlines. checkDeadlines(now) publishes DEADLINE_MISSED for overdue items; on hearing DEADLINE_MISSED it runs the escalation action once per item. The action is a std::function so it can be wired to Person 4's ApprovalHandler chain without this class depending on it.
