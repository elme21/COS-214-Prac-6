Detailed Description

ConcreteObserver: when a work item completes, tells the Mediator.

It calls Colleague::changed("completed") on the finished item. That reaches the WorkCoordinator (Mediator), which notifies every colleague. Each waiting WorkItem::receive() then asks canBecomeAvailable() and makes itself available. So this class never needs to know which items are waiting.

Sequence
ITEM_COMPLETED published -> update() -> item->changed("completed") -> WorkCoordinator::notifyChanged() -> each colleague's receive() -> canBecomeAvailable() -> makeAvailable().
Precondition
The published event carries the completed item (Event::item) and the items are registered with the coordinator.
Note
Events without an item are ignored.
See also
WorkCoordinator, WorkItem::receive()
