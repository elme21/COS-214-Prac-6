Detailed Description

The WorkItemState class is the State of the State pattern (WorkItem is the Context). Every lifecycle operation returns true if the transition happened and false if the current state does not allow it. The base implementation refuses everything; each ConcreteState overrides only the operations it allows. States are stateless and shared: each concrete state exposes static WorkItemState& instance(), and a WorkItem holds a NON-OWNING const WorkItemState* to it. The assignee lives on the WorkItem.
