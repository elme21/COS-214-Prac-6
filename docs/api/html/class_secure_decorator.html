Detailed Description

Role-based access control for a single task.

Only participants holding the required role can be assigned, and only the assigned participant, if they hold it, can approve, reject or complete. Compares the participant's role with the required one using Participant::getRole().

Design pattern
Decorator (ConcreteDecorator role).
