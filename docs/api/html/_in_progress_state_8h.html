class  InProgressState
 The InProgressState class is a ConcreteState of the State pattern: the assignee is working on the item. Allows complete() -> CompletedState, approve() -> CompletedState, reject() -> RejectedState, escalate() -> EscalatedState and cancel() -> CancelledState; makeAvailable(), assign() and start() are refused.
