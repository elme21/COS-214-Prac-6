Detailed Description

Wraps a WorkComponent, owns it, and forwards every operation to it.

Concrete decorators override only the operations they hook, plus clone(). A decorated task is still a WorkComponent, so the Composite, Iterator and Command code never needs to know whether a task is decorated.

Design pattern
Decorator (Decorator role). It also takes part in Prototype: clone() deep-copies the whole chain of wrapped components.
Note
getState(), getAssignee() and restoreState() are forwarded untouched on purpose, so undoing a command never re-triggers decorator hooks.
