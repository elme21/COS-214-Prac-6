AutomatedTask Class Reference

The AutomatedTask class is a ConcreteClass of the Template Method pattern (and a Composite leaf): an automated step that the system runs itself, with no person doing the work. Its primitive operation perform() runs the step and returns whether it succeeded. Detailed Description

The AutomatedTask class is a ConcreteClass of the Template Method pattern (and a Composite leaf): an automated step that the system runs itself, with no person doing the work. Its primitive operation perform() runs the step and returns whether it succeeded. On success, recordResult() completes the item; on failure the item stays InProgress, so it can be escalated and finished by hand.
