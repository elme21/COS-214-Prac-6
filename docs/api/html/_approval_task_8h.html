class  ApprovalTask
 The ApprovalTask class is a ConcreteClass of the Template Method pattern (and a Composite leaf): a task decided by a chain of approvers; the decision arrives as approve() or reject(). It is the Client of the Chain of Responsibility pattern. After each run of the chain it keeps the result as plain data (the handlers the request visited, who decided and what was decided), readable through the getChain...() getters. The result holds no pointers, so clone() simply copies it and a clone never refers back to the original task. More...
