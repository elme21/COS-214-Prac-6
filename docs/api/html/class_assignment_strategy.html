Detailed Description

Strategy: one rule for choosing who receives a work item.

route(item) chooses a participant from the candidates it was given and calls WorkItem::assignTo() on the item. The item's state machine may refuse (e.g. the item is not available yet); route() reports that through its result.

Adding a new rule
Derive from AssignmentStrategy, override route(), and pass the new object to TaskRouter::setStrategy(). No existing class changes.
Invariant
Strategies never own the participants or the item.
See also
TaskRouter, RoleBasedAssignment, WorkloadAssignment, RuleBasedAssignment
