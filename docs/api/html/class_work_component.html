Detailed Description

Common interface for every piece of work in a workflow.

Component of the Composite pattern (WorkStage = composite, WorkItem = leaf) and of the Decorator pattern (WorkComponentDecorator wraps any WorkComponent).

Lifecycle operations return true if the transition happened and false if it is not allowed (or unsupported, e.g. on a WorkStage). CommandProcessor only pushes a command onto its history when the operation returned true.
