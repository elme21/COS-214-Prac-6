Detailed Description

Owns finished workflow definitions and prototypical work components.

Instances are never built from scratch: callers clone a definition's root (see WorkflowDefinition::cloneRoot()) or a task prototype, so every running instance gets its own deep copy and one instance never affects another.

Design pattern
Prototype (PrototypeManager role). The Client is WorkflowManager, which creates instances; the Builder uses the task prototypes to create tasks by kind without a switch statement.
